# AI 校验采用双模型跨供应商、B 主导的审计流程

AI 校验负责把 LLM 翻译后的中文字幕对照原文做准确性把关。由于操作者可能不懂原文，人工只能抽查中文通顺度，无法复核原文准确性，因此流程必须由 AI 自身完成「审计 → 修正 → 复核」的闭环。我们决定：A 模型负责初译与执行修正，B 模型作为独立审计方拥有更高权威性；A 与 B 来自不同供应商以避免同源偏见；整个修正循环最多两轮，两轮后仍未解决的疑点以 Markdown 形式交人工判断中文通顺度。

## 已考虑的选项

- **单模型二次自检**：同一模型先翻译再自我审计。简单但无法避免训练数据与风格偏见。
- **同供应商双模型**：例如 DeepSeek V3 翻译、DeepSeek R1 审计。配置简单，但训练语料同源，仍可能共享盲区。
- **跨供应商双模型**：A 用 DeepSeek，B 用 Kimi。配置成本略高，但独立性最强。本期选择此项。

## 后果

- 操作者需要两个 LLM API Key（或网页端账号）。
- 校验模型 Kimi k3 是审计权威；翻译模型 DeepSeek V4 Pro 仅作为执行者。
- 流程文档必须提供可独立维护的提示词模板，不能依赖单一工具的预设功能。
- 人工只能处理「未解决疑点」，不能判断原文对错；中文通顺度抽查非必经。
