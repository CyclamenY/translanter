# 未解决疑点 Markdown 模板

此模板用于把第二轮 spot-check 输出的 `unresolved` JSON 转换为供人工抽查的 Markdown 清单。

## 生成规则

1. 读取 `spot-check-result.json` 中的 `unresolved` 数组。
2. 对每条未解决疑点，填充下表。
3. 保留 `entry_id` 便于在字幕编辑器中定位。

## 输出示例

```markdown
# 未解决疑点清单

> 来源：spot-check-result.json
> 人工只判断中文是否通顺/自然，不判断原文准确性。

| 条目号 | 分类 | 原文片段 | 当前译文 | 问题描述 | 置信度 |
|---|---|---|---|---|---|
| 203 | omission | ... | ... | 修正后仍可能漏译，B 无法给出可靠建议 | low |

## 抽查记录

| 条目号 | 是否通顺 | 修改后译文 | 备注 |
|---|---|---|---|
| 203 | 是 / 否 | ... | ... |
```
